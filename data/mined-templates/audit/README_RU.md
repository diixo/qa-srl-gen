# Результаты импорта в общий пул

Все ресурсы находятся в одном хранилище `data/mined-templates/`.
Отдельных рабочих банков `dailydialog-v38` и `candidates/` здесь больше нет.
Генерация и текущий аудит не требуют `data/dailydialog/review-parts/`.

| Материал | Где хранится |
| --- | --- |
| Опубликованные и кандидатные шаблоны | Общие `templates/*.jsonl.gz` |
| Глаголы, прилагательные, конструкции, сущности, именные группы, наречия | Общие корневые `*.jsonl.gz` |
| Разборы исходных предложений | Общие `occurrences/*.jsonl.gz` |
| Допущенные источники | `manifest.json` |
| Непроверенные диапазоны общих файлов | `pending.json` |
| 802 адаптации фрагментов | `reviewed/dialogue-fragments.json` |
| Ограничения карантина | `reviewed/dailydialog-quarantine.json` |
| Аннотации, решения, исходники и журналы | `audit/annotations/`, `audit/decisions/`, `audit/source/`, `audit/ledger/`, `audit/evidence/` |
| Исторические версии, базы разбора и результаты API | `audit/checkpoint/` |

## Общие файлы и допуск к генерации

В общие файлы добавлены исходные gzip-байты **101 353 кандидатных шаблонов**
и их словарей, а также четыре словаря: **897 сущностей, 12 853 кандидата
сущностей, 72 078 именных групп и 884 наречия**.
Прежние байтовые префиксы 339 файлов сохранены без изменений.

`pending.json` содержит статусы и диапазоны байтов, а не отдельный банк.
Повторный импорт с тем же ID не добавляет данные заново.
Непроверенные диапазоны исключены из обычной генерации.
Метка `REVIEWED` внутри отдельных старых записей сущностей не заменяет
семантический допуск всего импортированного словаря.

Рабочий индекс содержит 42 опубликованных источника, в том числе
5 613 шаблонов DailyDialog. Карантин сохраняет 19 нерешённых замечаний
и блокировку 21 вхождения. Перенос данных не меняет эти ограничения.

Для явного просмотра кандидатов:

```python
from semantic_corpus.template_bank import TemplateBank

bank = TemplateBank("data/mined-templates")
for source in bank.pending_components():
    print(source.source_id, source.manifest["counts"]["templates"])
```

Обычные `components()`, `templates()` и генерация читают опубликованные
диапазоны. Прямое чтение всего gzip-файла обходит это разграничение и может
включать непроверенные данные либо исторические версии записей.

## Сохранность аннотаций и проверка

`audit/import.json` связывает текущие пути, контрольные суммы и диапазоны.
Обозначение `v38` осталось в исторических материалах как версия проверки.

Проверены все **951 файл в 73 каталогах, включая корневой каталог**
исходной `review-parts/`: каждый совпадает с архивом по SHA-256.
Все шесть файлов ручных аннотаций также побайтно сохранены в
`audit/annotations/`. Их **3 755 реплик из 510 диалогов** представлены
в опубликованных источниках: сверены отпечатки полных аннотаций и записи
общего `sentence_review.jsonl.gz`.

```powershell
python -X utf8 -B scripts/audit_dailydialog_quarantine.py --out artifacts/shared-pool-audit.json
python -X utf8 -B scripts/dailydialog_checkpoint.py verify --bundle data/mined-templates/audit/checkpoint
```

Аудит и пробная генерация прошли с запретом чтения старых `review-parts/`
и `artifacts/`: [проверка независимости](verification-pool-only.json).
Это проверка сохранности и работы импорта; она не означает нового
семантического допуска всего кандидатного банка.

Архив содержит **2 029 файлов**, включая все 951 файл `review-parts/`,
ручные разборы и 47 077 результатов API. Его 25 ZIP-томов занимают
около 1,07 ГиБ. Проверено восстановление и повторное чтение 161 312
сегментов. Секреты из `.env` и веса моделей в архив не входят.

Полная сверка: [verification.json](checkpoint/verification.json).
Список для коммита: [commit-files.json](checkpoint/commit-files.json).
Общие файлы, оба индекса, `reviewed/` и `audit/` следует сохранять вместе.
`.gitattributes` защищает точные байты от преобразования LF/CRLF.

## Старые ссылки в artifacts и очистка

В текстовых файлах `artifacts/` найдены 495 файлов с упоминаниями
`review-parts`, без проверочных и резервных копий; среди них 219 Python-скриптов.
Некоторые старые скрипты подготовки и проверки действительно требуют
исходную рабочую папку при повторном запуске. Её можно восстановить из
архива. Исторические пути и журналы не переписывались.

Этот поиск не является полным аудитом всех сжатых файлов, SQLite-баз и
весов моделей в `artifacts/`. У 370 найденных исходных файлов нет точной
сохранённой копии в проверенном архиве или обычных файлах импорта:
это включает 200 старых скриптов и пять промежуточных compiled JSONL.
Отсутствие такой копии не означает потерю их итоговых исправлений,
но не позволяет считать всю `artifacts/` безопасной для удаления.

Список найденных файлов, их SHA-256 и сохранённых копий находится в разделе
`artifacts_review_parts_references` файла
[verification.json](checkpoint/verification.json).
Условия очистки: [cleanup.json](checkpoint/cleanup.json).

19 октября 2026 года после повторной сверки SHA-256 удалены **6 116 файлов-копий**.
Рабочая `data/dailydialog/review-parts/` удалена полностью; её 951 файл остаётся
в проверенном архиве. Удалены также подтверждённые копии из перечисленных
в `cleanup.json` рабочих и проверочных каталогов. Сам `cleanup.json` сохранён
как исторический план, отражающий состояние до этой очистки.
Суммарный логический объём удалённых файлов — 10 596 399 466 байт;
освобождённое место не измерялось, поскольку часть копий была жёсткими ссылками.

Четыре файла без точного сохранённого совпадения оставлены: временная
`revision.sqlite3`, два JSON-снимка прежней раскладки и `journal.sqlite3-shm`.
Остальные эксперименты и старые банки не удалялись.
Исторические инструменты при необходимости запускаются после восстановления
нужных файлов из архива. Текущая генерация читает общий пул.

## Локальное пополнение для Extraction — 2026-10-19

В общий каталог добавлены **30 адаптаций из 17 диалогов**: три текущих чувства,
шесть событий с явными участниками и модальностью, 21 контекстная интерпретация.
Прочитаны диалоги `train:501–525`; это не означает допуска всех их предложений.
Исходные реплики сохранены дословно. Поясняющий запрос делает видимыми только
проверенные антецеденты; область допуска ограничена этой парой реплик.

Способность, необходимость, предложение и будущее действие не считаются
подтверждением выполнения. Вопросы, условия и альтернативы сохраняют свой статус.
Адаптации, исходные реплики и обоснования находятся непосредственно в общем
каталоге [dialogue-fragments.json](../reviewed/dialogue-fragments.json), в полях
`source` и `review`. Генератор читает этот каталог; отдельной копии адаптаций нет.

Прежние 772 адаптации сохранены. Опубликованные диапазоны и реестр
карантина не изменены: 101 353 шаблона и исходные четыре словаря остаются кандидатами,
19 неоднозначных замечаний по-прежнему блокируют 21 вхождение.

Генератор учитывает проверенные буквальные значения location/feeling/drink
при выборе начального контекста, чтобы новые значения не исчерпывали допустимые
варианты проверочной выборки. Ограничение всех видимых состояний одной выборкой
сохранено. После исправления прошла 1 641 целевая проверка генерации и Extraction.

## Проверенные сущности — 2026-10-19

Разобраны 897 записей кандидатного `entities.jsonl.gz`. Для 402 записей такое
чтение уже было в Built-in pool: их типы и дополнительные сведения сохранены
без дублирования. По 477 записям добавлены **478 чтений** в существующую сущностную
часть пула — `semantic_corpus/semantic_generator/entities.json`. Теперь пул
содержит 5 489 чтений вместо 5 011: добавлены 248 PERSON, 203 LOCATION,
26 ORGANIZATION и одно ANIMAL. Новых типов и отдельных банков не создавалось.

Каждое новое чтение связано с точным контекстом исправленного исходника.
У Lulu два разных контекста: коллега (`val:577`) и попугай (`val:978`), поэтому
добавлены два чтения с пояснениями. Grangerfield исправлен с PERSON на LOCATION:
диалог явно называет его городом. Tasha сохранено как название места без
догадок о другом написании. В полных именных группах учтены артикли; у
`the Alps` и `the Rocky Mountains` указано множественное число.

**18 записей не допущены**: среди них ошибочно выделенные имена, названия
карт, фильмов, команд и товаров с неподтверждённым типом. Это отдельные решения
по словарю, не прежние 19 замечаний, блокирующих 21 вхождение предложений.
Исходные данные и кандидатные диапазоны сохранены. Старые флаги REVIEWED
в строках кандидата не означают автоматического допуска его употреблений.

Результаты рассмотрения всех 897 записей прикреплены к исходному словарю в
[pending.json](../pending.json): источник `dailydialog-resources`,
`review.entities.jsonl.gz`. Там сохранены ссылки на принятые чтения в общем пуле,
адреса подтверждающих реплик и причины 18 отказов. `row_index` начинается с нуля;
адрес реплики имеет вид `split:dialogue:turn` с нумерацией от единицы. Полные
контексты читаются из [audit/source](source), контрольные суммы исходников сохранены.
Данные для генерации находятся в `entities.json` и `reviewed/dialogue-fragments.json`;
сведения о рассмотрении в `pending.json` сами по себе ничего не публикуют.
Исходные сжатые диапазоны не переписаны. Остальные три словаря и 101 353 шаблона
этим шагом не допущены. Четыре дублирующих отчёта `local-*-20261019.json` удалены;
нового реестра или отдельного банка не создано.

Проверка пополненного пула выявила утечку составных имён: `Nathaniel Brown`
попадал в train по фамилии Brown, хотя Nathaniel относился к test. Теперь
разделение учитывает все содержащиеся имена с приоритетом test → dev → train.
Обычные имена с единственным основанием разделения сохраняют прежнюю выборку.
Это исправление может изменить выборку составного имени; ранее созданные
датасеты не переписываются.

Каждое из 478 чтений явно подставлено в подходящий слот: проверены 3 824
предложения с активным/пассивным залогом, прошедшим/настоящим временем и
отрицанием, сформированы 33 708 QA-примеров. Проверены типы, согласование и
границы; это техническая проверка генерации, а не измерение качества обучения.
Утечек именных форм между train/dev/test в текущем пуле не обнаружено.
После исправления прошли **105 тестов** пула, онтологии, генерации, CLI и
диалогового Extraction. Прежние строки сущностного пула, четыре кандидатных
словаря, исходники, шаблоны и реестр карантина сохранены без изменений.
